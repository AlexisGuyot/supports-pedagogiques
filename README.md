# Supports pédagogiques d'Alexis Guyot

Cours, TD, TP et projets d'informatique conçus dans le cadre de mes enseignements à
l'IUT d'Aix-Marseille (département Informatique) et, auparavant, à l'UFR
Sciences et Techniques de Dijon, partagés en licence libre. Enseignant·e ou étudiant·e, vous pouvez les télécharger,
les adapter et les redistribuer, à condition de citer la source et de
partager vos versions modifiées sous la même licence. Les corrections des exercices peuvent être fournies à la demande (alexis.guyot@univ-amu.fr), à condition de ne pas être repartagées ailleurs.

## Organisation du dépôt

Tous les supports sont rangés dans [`supports/`](supports), selon le schéma
`Composante / Niveau / Module / Section`. Dans chaque section (CM, TD, TP,
Projet, Ressources complémentaires…), les versions à jour sont à la racine ;
les versions antérieures sont rangées dans un sous-dossier dont le nom
indique leur période d'utilisation (par exemple `2021-2023`).
